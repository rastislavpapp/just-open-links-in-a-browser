# just open links in a browser

Android apps love opening links in an in-app browser: a bare little window
inside the app, with one page, no tabs, and nothing left when you close it.

This app sends those links to your real browser instead. Set it as your default
browser, then open it once to pick which browser links should go to.

Some apps go further and draw the page themselves (Facebook, Instagram). Those
never hand the link over at all, so nothing can help there.
